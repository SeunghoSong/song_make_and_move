# 📌 [CCTV 출석 확인 엣지 AI] 현장 조사 체크리스트

## 1. CCTV 카메라 기본 사양 및 배치
- [x] **설치 위치 및 대수**: [ ] 단일 카메라 / [x] multi-camera ( [ 2 ]대 )
  > *이유: 멀티 카메라 환경일 경우 중복 감지 제거(Non-Maximum Suppression) 및 카메라 간 객체 추적(Re-ID) 전처리가 필수적입니다.*
- [x] **카메라 설치 높이 및 감지 거리**: [ ] 2m 이하 / [ ] 2m~3m / [x] 3m 이상 | [ ] 5m 이내 / [ ] 5m~10m / [ ] 10m 이상
  > *이유: 높이와 거리에 따라 얼굴 영역의 픽셀 해상도(Bounding Box 크기)가 달라져 리사이징 및 Upsampling(초해상도) 필터 적용 여부를 결정합니다.*
- [x] **수평/수직 하향 각도(Tilt/Pitch)**: [ ] 15° 미만 (정면) / [x] 15°~45° (중간) / [ ] 45° 초과 (고각)
  > *이유: 정수리가 주로 보이는 고각 환경에서는 얼굴 감지 정확도가 급감하므로 3D Pose Estimation이나 Perspective Transformation(투시 변환) 전처리가 요구됩니다.*
- [x] **해상도 및 Frame Rate**: [x] FHD(1080p) 이하 / [ ] 4K 이상 | [x] 15fps 이하 / [ ] 30fps 이상
  > *이유: 엣지 디바이스의 리소스 한계를 고려한 동영상 프레임 샘플링(Skip-frame) 간격 설정의 기준이 됩니다.*

## 2. 조명 및 광원 환경
- [x] **주 광원 종류**: [x] 형광등/LED (수평 균일) / [ ] 창문 자연광 (측면/역광) / [ ] 빔프로젝터 중심 (부분 암전)
  > *이유: 광원 위치에 따른 명암 대비차 극복을 위해 CLAHE(국소 영역 히스토그램 평등화) 또는 Gamma Correction 알고리즘을 선별 적용해야 합니다.*
- [x] **시간대별 광원 변화 정도**: [x] 일정함 / [ ] 시간에 따라 광원 위치/밝기 변화 큼
  > *이유: 동적 조명 환경에서는 프레임 단위의 Brightness Normalization(밝기 정규화) 전처리가 필수적입니다.*
- [x] **주요 장애 요소**: [ ] 역광(창문 등) / [x] 플리커(Flicker) 현상 / [ ] 반사광 / [ ] 해당 없음
  > *이유: 플리커 제거 디노이징 필터나 역광 보정용 Adaptive Thresholding 기술 필요 여부를 판단하기 위함입니다.*

## 3. 강의실 내부 구조 및 피사체(학생) 환경
- [x] **좌석 형태**: [x] 계단식 좌석 / [ ] 평지 일자형 좌석 / [ ] 그룹형(원형/모둠) 좌석
  > *이유: 계단식 좌석은 가림(Occlusion)이 적은 반면, 평지 일자형은 앞사람에 의한 가림 현상이 심해 Occlusion Handling 전처리가 요구됩니다.*
- [x] **얼굴 가림(Occlusion) 주요 요소**: [x] 모자/마스크 / [ ] 노트북/모니터 화면 / [ ] 앞사람 머리/필기 자세 / [ ] 없음
  > *이유: 가려진 영역을 복원하거나 가려짐 정도를 계산하는 Bounding Box filtering threshold를 설정하기 위함입니다.*
- [x] **얼굴 각도 범위(Yaw/Pitch/Roll)**: [x] 대부분 정면(±15°) / [ ] 측면 주 시선(±45°) / [ ] 고개 숙임/필기 위주(>45°)
  > *이유: 측면 및 숙인 얼굴 식별을 위한 Face Alignment 및 Landmark detection 알고리즘 파이프라인을 결정합니다.*

## 4. 엣지 AI 디바이스 및 네트워킹
- [x] **엣지 AI 디바이스 성능**: [x] 초저전력(NPU/MCU급) / [ ] 중간(Jetson Nano/Xavier급) / [ ] 고성능(Jetson Orin/고성능 Edge Server급)
  > *이유: 연산 보드 성능 한계에 따라 Heavy한 이미지 연산(Blur, Deep Super Resolution 등)을 제외할지 여부를 결정합니다.*
- [x] **네트워크 전송 방식**: [ ] 로컬 온디바이스 완결 / [x] 프레임 크롭 후 중앙 서버 전송 / [ ] 전체 RTSP 스트리밍
  > *이유: 네트워크 대역폭 절약을 위한 ROI(관심영역) Crop 및 이미지 압축(JPEG Lossy Compression) 알고리즘 적용 수준을 파악합니다.*
